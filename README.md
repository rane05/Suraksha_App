# 🛡️ Suraksha Setu – Citizen & Police Safety Ecosystem

## 📱 Mobile App (Citizen) & 💻 Web App (Police)

**Suraksha Setu** is a real-time public safety solution that bridges the gap between citizens and law enforcement. It empowers both parties through instant communication, AI-based surveillance, and geo-enabled emergency support. Built to respond faster, act smarter, and ensure safer communities.

- 📱 **Mobile App** – Developed in **React Native**  
- 💻 **Police Dashboard** – Developed with **HTML + Tailwind CSS**  
- 🧠 **AI-powered Backend** – Built using **Python Flask**  
- 🗄️ **Database** – MongoDB

---

## 🔍 Key Features

### 👥 Citizen Mobile App
- **🆘 SOS Button** – One-tap emergency alert with live location sent directly to the police dashboard.
- **📍 Live Location Tracker** – Real-time location sharing in distress or active cases.
- **📝 Incident Reporting** – Citizens can report:
  - Crimes
  - Accidents
  - Suspicious behavior
- **📥 Police Alerts** – Citizens receive real-time safety warnings and alerts from authorities.

### 🛡️ Police Web Dashboard
- **📌 Real-Time Incident Monitoring** – Interactive map showing all incoming reports.
- **📊 Alert Broadcasting** – Send urgent alerts to citizens based on zones.
- **🎥 CCTV/Media AI Analysis** – Upload media for instant weapon/missing person detection.
- **📈 Analytics** – Analyze patterns of crime, risk zones, and response rates.

---

## 🧠 AI & Machine Learning Modules

- **🔫 Weapon Detection (YOLOv8)**  
  Detects both visible and concealed weapons from video/images.

- **🧍 Missing Person Recognition (FaceNet/DeepFace)**  
  Matches uploaded images with a missing persons database.

- **🎯 Concealed Object Prediction**  
  AI detects abnormal shapes under clothes or in bags indicating hidden weapons.
